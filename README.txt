BINTANG MULIA TOUR TRAVEL — WEBSITE STATIS

Isi folder:
- index.html : struktur dan konten website
- style.css  : desain, warna, layout responsif
- script.js  : menu mobile, tahun otomatis, dan formulir WhatsApp

Cara melihat:
1. Ekstrak ZIP jika memakai file ZIP.
2. Buka index.html di browser untuk melihat preview lokal.
3. Untuk dipublikasikan, unggah ketiga file ke hosting statis (mis. Netlify, GitHub Pages, atau hosting domain sendiri).

Penting:
- Formulir tidak menyimpan data ke server. Formulir menyusun pesan lalu membuka WhatsApp tujuan 0858-7630-0013.
- Harga, paket resmi, jenis armada, dan fasilitas belum diklaim karena perlu konfirmasi pemilik bisnis.
